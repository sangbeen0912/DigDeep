# 돈·에너지 아이콘과 튜토리얼 가독성

## 적용 내용
- 강화 확인창의 돈·에너지 사각형 표시를 금화·번개 코어 이미지로 교체했다. 광물 아이콘과 동일한 23×23 영역을 사용하고 비율을 유지한다.
- 인벤의 에너지에도 같은 아이콘을 사용한다. 별도의 중복 리소스를 만들지 않는다.
- 튜토리얼 행동 안내는 14에서 22 크기의 굵은 글자로 바꾸고, 단계 제목과 보조 설명은 17로 표시한다. 행동 단어를 금색으로 강조하고 왼쪽에 정렬한다.
- 설명 배경은 불투명한 어두운 색으로 처리하고 그림자·금색 강조선을 넣었다. 주변 어둡기와 대상 테두리의 최소 밝기를 높였다.
- 긴 문단을 행동 한 줄과 짧은 보조 설명으로 나누었다. 시작 안내와 중복되는 작은 Dig!! 안내는 튜토리얼 중 숨긴다.
- 일반 안내는 화면 아래, 메뉴를 연 상태에서는 위쪽의 비활성 HUD 영역에 놓는다. 설명이 조작 대상, 재료 표, 뒤로가기 버튼을 가리지 않는다.
- 기존 진행 순서·완료 기록·필수 행동과 돈·광물·에너지·강화·최고 기록 저장은 바꾸지 않는다. 완료한 튜토리얼을 다시 시작하지 않는다.

## 리소스
- `Assets/DigDeep/Art/MoneyIcon.png`: 금화
- `Assets/DigDeep/Art/EnergyIcon.png`: 번개가 들어간 청록색 에너지 코어
- builtin imagegen으로 생성했으며 원본 픽셀을 수정하지 않고 유니티 슬라이스로 적용한다. 최대 텍스처 128, Point 필터, Mipmap 없음, 런타임 읽기 없음이다.
- 기존 표시는 코드로 그리던 색 사각형이므로 삭제할 이전 이미지 파일은 없다. 다른 기존 아트는 계속 사용하므로 보존한다.
- 정확한 생성 프롬프트와 절대 저장 경로는 `Readability-Art-Prompts-2026-10-20.json`에 기록한다.
