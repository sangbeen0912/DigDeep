# 버튼 리소스·최고 깊이·발표 도구

## 적용 내용
- 상점·인벤·강화 버튼은 64×50에서 80×50으로 확장했다. 순서를 유지하며 오른쪽 영역에 8칸 간격으로 배치한다.
- Dig!!는 기존 230×64 크기를 유지하며 금색 픽셀 리소스와 기존 나무 곡괭이 아이콘을 사용한다.
- 튜토리얼 강조 테두리와 터치 판정은 실제 버튼 RectTransform에서 영역을 얻는다. 화면 배율이 달라져도 같은 영역을 공유한다.
- 최고 도달 행을 성장 정보로 자동 저장한다. 현재 판의 깊이와 구분하여 표시하고, 이전 기록을 처음 넘을 때 판마다 한 번 안내한다. 이후 더 깊은 행의 기록은 계속 저장한다.
- 게임 오버·재정비·재접속 후에도 최고 기록을 유지한다. 데이터 초기화 시 최고 기록도 0으로 돌아간다.
- 저장 형식 6은 이전 형식 1~5를 읽고 돈·광물·곡괭이·강화·확인 기록·튜토리얼 진행을 보존한다. 이전 형식에 없던 최고 깊이는 0부터 기록한다.
- 채굴 종료 결과에는 이번 판에서 도달한 깊이(행)만 표시한다. 돈·광물 내역과 추가 안내 문구는 표시하지 않는다. 실제 획득 재화는 인벤 및 저장에 정상 반영한다.

## 발표용 버튼
- 대기 화면 왼쪽 위에 별도로 배치하며 플레이 중과 다른 창을 연 동안 사용할 수 없다.
- 한 번 누르면 돈 20,000원, 석탄 200개, 철광석 100개, 금광석 30개를 추가하고 자동 저장한다. 반복 지급도 가능하다.
- 광물 확인 기록을 함께 추가하므로 판매와 강화에 사용할 수 있다. 튜토리얼 진행·최고 기록·현재 판의 획득량은 바꾸지 않는다.
- `Assets/DigDeep/Prefabs/DigDeepGame.prefab`의 `PresentationTools` 자식을 삭제하면 이 버튼만 제거된다. 일시적으로 끄려면 해당 자식의 `PresentationResourcesButton` 컴포넌트를 비활성화한다.
- 코드까지 삭제하려면 `Assets/DigDeep/PresentationTools` 폴더 전체와 해당 .meta를 삭제한다. 핵심 게임 코드는 이 모듈의 타입에 의존하지 않는다. 이미 지급하고 저장한 재화는 유지된다.
- `UiRecordSetup.ApplyAndVerify`는 최초 적용용으로 이 모듈을 설치한다. 제거 후 이를 다시 실행하면 모듈이 재설치된다. 일반 웹 빌드는 재설치하지 않는다.

## 리소스
- AI 이미지 생성 도구(imagegen, builtin)로 만든 투명 PNG를 사용한다. 원본 픽셀을 수정하지 않고 유니티 Sprite 슬라이스와 테두리 설정으로 적용한다.
- `MenuButtons.png`: 기존 승인된 버튼 시트. 슬레이트 테두리·황동 모서리·상점/가방/망치 아이콘, 글자는 유니티에서 표시한다.
- `DigButton.png`: 같은 테두리 계열의 금색 버튼. 글자와 곡괭이 아이콘은 유니티에서 별도로 표시한다.
- 최대 텍스처 크기는 1024이며 Point 필터, Mipmap 없음, 런타임 읽기 없음이다. 기존 땅·광물·곡괭이 시트는 계속 사용하므로 보존한다.

## 검증
플레이어 빌드 없이 유니티 에디터 컴파일·격리된 저장 키를 사용하는 기능 검사·실제 UI 캡처로 확인한다. 검증 결과는 `Logs/MiningUpgrade/ui-record-checks.txt`, 캡처는 같은 폴더의 60~66 번호 PNG에 기록한다. 실제 사용자 저장 및 공개 GitHub Pages 배포는 변경하지 않는다.
