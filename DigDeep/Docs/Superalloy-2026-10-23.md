- 탭/홀드/대상 블록 드롭 채굴이 모두 같은 속도를 사용한다. 홀드 인식은 0.28초를 유지한다. 손을 떼거나 곡괭이를 바꾸면 기존 스윙을 취소한다.
- 실제 피해가 발생할 때만 내구도 1을 소모한다. 에너지는 채굴 중 소비하지 않는다.
- 강화 확인창 아래에 현재 → 다음 속도 배율을 표시한다.

## 강화

- 합금 → 다이아: **1,000원 + 다이아 20개 + 에너지 5.0**. 돈만 500원에서 1,000원으로 변경한다.
- 다이아 → 초합금: **2,000원 + 철광석 50개 + 다이아 10개 + 에너지 10.0**.
- 자원이 하나라도 부족하면 강화는 실행되지 않고 어떤 자원도 차감하지 않는다. 성공 시 자원 차감과 새 곡괭이를 함께 저장한다.
- 초합금은 이번 버전의 마지막 단계다. 소유 목록·대기·채굴·제련에서 새 스프라이트를 표시한다.
- 드릴/포크레인/착암기/분쇄기 네 루트와 루트별 후속 강화는 미래 기획이다. 이번 코드와 강화 목록에는 추가하지 않았다. 비용·세부 능력치·후속 장비명은 미정이다.

## 변환

- 석탄 1개 → 에너지 0.1 유지.
- 석유 1개 → 에너지 1.0 추가.
- 에너지는 기존 정수 0.1 단위를 사용한다. 석유 1개는 10단위다. 소수점 누적 오차와 정수 범위 초과를 방지한다.
- 변환 탭에서 선택한 광물 행이 끝까지 보이도록 위치를 조정한다. 미발견 광물의 판매 숨김 규칙은 유지한다.

## 저장과 리소스

- 기존 저장 형식 7을 유지하고 `SUPERALLOY` 장비 ID를 허용한다. 1~7의 기존 저장을 읽는다. 필드 구조 변경이나 초기화 없이 성장·확인 기록·튜토리얼·최고 기록을 유지한다.
- 곡괭이 능력치와 속도는 설정에서 읽으므로 기존 보유 철/합금/다이아에도 새 속도가 적용된다. 장비별 속도를 저장에 중복 기록하지 않는다.
- `Assets/DigDeep/Art/SuperalloyPick.png`: imagegen으로 생성한 짙은 금속색·붉은 포인트 픽셀 이미지. 기존 돌 곡괭이와 같은 슬라이스 비율, 기존 표시 각도와 크기를 사용한다. 최대 512, Point, 밉맵 없음, 런타임 읽기 없음.
- 기존 이미지는 계속 사용하므로 삭제하지 않는다. 정확한 프롬프트·절대 경로·생성 방식은 `Superalloy-Art-Prompt-2026-10-23.json` 참고.
