# 성장 저장 및 UI 변경

- 시작 버튼과 안내 문구는 `Dig!!`. 대기 화면의 큰 복합 패널을 없애고 시작 버튼만 중앙보다 아래에 배치.
- 상점/강화는 돈 아래 각각 별도 버튼과 개별 화면. 구매/강화 실제 동작은 아직 준비 중.
- 재정비는 곡괭이 보관 UI 아래. 플레이 도중 사용 가능. 아무 페널티 없이 돈/장비/강화 유지, 지형 초기화, 전 곡괭이 회복, Dig!! 대기.
- 데이터 초기화는 오른쪽 아래. 플레이 중에는 숨겨 조작 불가. 첫 경고 → 최종 경고 → 초기화. 각 단계 취소 가능.
- 성장 저장: 돈, 곡괭이 ID/공격력/최대 내구도/강화 단계. 현재 내구도와 지형/위치/대상은 저장 안 함.
- 기존 돈 저장을 새 성장 저장으로 이전 지원. 재접속은 언제나 새 지형과 회복된 장비로 대기.
- 파괴 보상 지급 시 및 화면 이탈/종료 시 자동 저장. 향후 실제 구매·강화에서 SaveGrowth() 호출 필요.
- 잘못된 저장은 이전 스냅샷 복구 시도. 둘 다 잘못되면 원본 덮어쓰기 방지 및 안내.
- 초기화는 게임의 저장 키만 갱신. 다른 앱/게임 데이터에 영향 없음.
- 현재 테스트용 나무/철 곡괭이 두 개 유지. 초기화 후에도 두 개 지급. 나무 하나로 바꾸는 작업은 미실시.
- 곡괭이 머리 비중을 키우고 손잡이를 줄인 CompactPickaxes.png 사용. 기존 MiningAtlas의 블록과 원본은 보존.
- 아트: 내장 image_gen. 원본 아틀라스 참조, 머리와 손잡이의 길이 비중이 비슷한 짧고 두툼한 픽셀 곡괭이 두 개, 투명 배경. Sprite Importer로 좌우 분할.
- 이번 작업은 플레이어 빌드 없이 컴파일 및 에디터 테스트로 검증.

기존 제작-기준.md와 충돌하는 UI/저장 설명은 이 문서가 최신 기준이다.
