# 디그딥 첫 플레이 버전

## 적용 범위
- Unity 6000.3.23f1, 모바일 웹을 목표로 하는 480×854 세로 화면. 가로 5칸.
- 공통 입력 컨트롤러가 UI, 탭, 홀드, 드래그를 하나의 포인터로 처리한다.
- 탭은 떼었을 때 1회 타격한다. 홀드 시작 후 손을 떼면 즉시 중단하며 추가 탭은 발생하지 않는다.
- 곡괭이를 직접 누르면 드래그 후보이며 채굴 영역과 분리한다.
- 드래그 이동은 좌우와 위쪽으로만 가능하다. 시작 위치 기준 위 5칸 이내.
- 게임이 빈 칸 경로를 찾는다. 중간 블록 통과와 아래 이동은 금지한다. 도착 블록만 채굴 가능하다.
- 빈 칸 드롭은 무료 이동. 잘못된 드롭은 행동 취소, 실제 위치와 블록/장비 수치는 유지한다.
- 피해량 = min(공격력, 블록 남은 체력, 곡괭이 남은 내구도). 내구도는 피해량만큼 감소한다.
- 대상이 남으면 곡괭이는 블록 앞에 머문다. 왼쪽 위에서 다른 곡괭이를 수동 선택하면 대상과 위치를 유지한다.
- 모든 보유 곡괭이 내구도가 0일 때 게임 오버. 장비는 삭제되지 않는다.
- 재시작 시 지형과 부분 피해는 초기화, 모든 곡괭이 내구도 회복, 돈 유지, PLAY 대기.
- 돈과 곡괭이 UI는 플레이 중 유지한다. 시작/상점/강화는 플레이 중 숨겨 사용 불가.
- 광물 및 실제 구매/강화 기능은 이번 범위에서 제외한다.

## 프로토타입 선택 사항 (최종 밸런스 아님)
- 기본 블록 체력 12 / 파괴 보상 2G.
- 나무 곡괭이 공격력 4, 내구도 120 / 철 곡괭이 공격력 6, 내구도 180. 수동 교체 검증용 2개 지급.
- 홀드 판정 0.28초, 타격 간격 0.34초, 드래그 시작 거리 기준 화면 10단위.
- 블록 드롭 시 해당 블록 하나를 파괴하거나 내구도를 소진할 때까지 반복 타격한다.
- 드롭 반복 타격은 다시 곡괭이를 잡으면 취소된다. 부분 피해와 대상은 유지된다.
- 휘두르기/반동, 균열, 파편. 피해는 애니메이션의 충격 시점에 적용한다.
- 설정은 Assets/DigDeep/GameSettings.asset에서 조정한다.
- 돈은 PlayerPrefs에 저장한다. 웹에서는 브라우저 로컬 저장이므로 브라우저 데이터 삭제 시 사라지며 계정 간 동기화는 없다.

## 파일 구조 및 실행
- 씬: Assets/DigDeep/Scenes/DigDeep.unity
- 프리팹: Assets/DigDeep/Prefabs/DigDeepGame.prefab
- GameManager: 상태 전환, 타격 타이밍, 저장.
- MiningSession: 블록/곡괭이 규칙과 경로 탐색. 화면 독립적인 로직.
- PointerController: 포인터 소유권, UI 구분, 탭/홀드/드래그.
- GameView: 런타임 Canvas와 화면 생성. UI는 플레이할 때 생성된다.
- Editor 메뉴 DigDeep → Validate game rules: 자동 규칙 검증.
- Editor 메뉴 DigDeep → Build mobile web: 웹 빌드 (같은 버전의 Web Build Support 필요).
- 원래 SampleScene은 보존하고 새 DigDeep 씬을 빌드 대상으로 설정한다.

## 아트 출처
- MiningAtlas.png: 내장 image_gen으로 이번 프로젝트용 생성.
- 생성 지시: 2×2 투명 스프라이트 아틀라스, 정면 회색 돌/잔디 흙 블록, 나무/철 곡괭이, 마인크래프트풍 픽셀 질감, 광물·문자·UI 없음.
- 원본 아틀라스를 Sprite Importer로 분할하며 픽셀 보간은 Point 사용.
- 상단 HUD는 질감 없는 단색.
- Noto Sans KR: Google Fonts, SIL Open Font License. Fonts/OFL.txt 포함.

## 후속 기획
- 실제 광물, 구매/강화 효과와 가격, 영구 성장 및 장비 추가 저장.
- 드롭 자동 채굴의 감각과 홀드/타격 수치 플레이 테스트.
- 실제 모바일 Safari/Chrome에서 터치, 백그라운드 전환, 저장 유지 검증.

## 검증 결과
- Unity 컴파일 및 씬/프리팹 생성 성공.
- 독립 규칙 검증 21개 통과: 내구도 부족, 초과 피해 방지, 부분 피해 유지, 교체, 경로, 높이 제한, 재시작과 돈 유지 등.
- Windows 테스트 빌드 성공. 실행 시 시작 버튼, 탭 1회, 홀드 해제 정지, UI 입력 분리, 수동 교체, 게임 오버, 재시작 자동 검증 통과.
- Builds/Verification에 대기/채굴/게임 오버 실제 렌더링 이미지와 smoke-result.txt 보관.
- 테스트 빌드 실행 파일: Builds/Desktop/DigDeep.exe.
- 현재 설치된 Unity에는 Web Build Support가 없어 웹 빌드와 실제 모바일 브라우저 검증은 미완료.
- Unity Hub에서 6000.3.23f1의 Web Build Support를 추가한 뒤 DigDeep → Build mobile web 실행. 결과는 Builds/Web.
